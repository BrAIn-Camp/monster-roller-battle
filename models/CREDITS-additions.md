## Notes

- **External texture.** GLBs from every pack above except Nature Kit and Space Kit reference
  `Textures/colormap.png` relative to the GLB. That file was copied to `models/kenney/<folder>/Textures/colormap.png`
  and must stay there. Each pack has its own colormap. In `graveyard/`, `town/` and `food/` the texture is used only
  by the newly added kebab-case files; the older camelCase files are self-contained.
- **Versions in mixed folders.** `graveyard/`, `town/` and `food/` now hold the older files credited in `CREDITS.md`
  (2020 versions from the GitHub mirror) plus additions from the current versions (Graveyard Kit 5.0,
  Fantasy Town Kit 2.0, Food Kit 2.0). `nature/` is Nature Kit 2.1 throughout; the official archive is the same
  version as the files already present.
- **Left out on purpose.** Floor, road, ground and path tiles, modular house walls and roofs (Fantasy Town, Holiday
  cabin pieces), most modular cliff blocks, platformer terrain blocks, corridor and monorail pieces, character
  models, and modular conveyor variants.
- **Not requested by name but added.** Factory Kit was taken as the "similar industrial/factory kit". Space Kit was
  added to cover power-station machinery, satellite dishes, pipes, crystal rocks and craters, which no requested
  pack has. "mini-market" is called Mini Shop on kenney.nl.
- **Skipped.** Furniture Kit and Hexagon Kit (not needed). Quaternius packs: quaternius.com only offers downloads
  through Google Drive links, which were ruled out, so nothing was taken. poly.pizza was not used.
